# Programs

An index of Endless Access's program offerings. Each subfolder holds one program's materials in the same two-file pattern:

- **curriculum.md** -- the reference document: program shape, extraction/fidelity notes, learning principles and outcomes, requirements, and a session or workshop map. Read this first to understand what a program is and how it's structured.
- **sessions.md** -- the actual content taught: every session or workshop in full, in delivery order, ready to run.

Content in `sessions.md` files is reproduced verbatim from the original source decks and docs, including any gaps the extraction couldn't recover -- gaps are flagged inline rather than filled in. Nothing here has been rewritten or summarized from the source material.

## Programs

### [Core: Threadbare](Core-Threadbare/)

The flagship program: a structured, cohort-based game-making experience across five milestones. Learners build and submit a StoryQuest -- a Godot mini game for the live *Threadbare* repo -- via GitHub pull request. Tied to the Community Game Making microcredential (7 criteria).

- `curriculum.md` -- program front matter, learning principles, learner outcomes, milestone overview
- `sessions.md` -- all 18 sessions across 5 milestones, in full
- `learner-playbook.md` -- companion self-directed guide for learners working through milestones on their own

### [Explore: Threadbare](Explore-Threadbare/)

A modular, non-cohort program: 13 standalone one-hour workshops across four disciplines (Game Design, Art, Engineering/Management/Production, Go-To-Market), each a self-contained session a learner can join on its own. The only NDPA-compatible program in the MVP, so the default for US school partnerships.

- `curriculum.md` -- program shape, common workshop arc, workshop map by discipline
- `sessions.md` -- all 13 workshops, in full

### [Explore: Godot](Explore-Godot/)

A 10-session cohort course, 60 minutes per session, teaching game-making fundamentals through modding and level design. First Endless-led online cohort ran May 12 - June 11, 2026.

- `curriculum.md` -- program shape, fidelity notes, session map
- `sessions.md` -- all 10 sessions, in full

### [Educator Training Program](Educator-Training-Program/)

Facilitator-facing, not learner-facing: this is how educators are trained to run Core: Threadbare, not a program delivered to kids directly. Covers pedagogy, requirements, and a live "Walk the Walk" modeled session.

- `curriculum.md` -- the Facilitator Playbook: requirements, learning principles, outcomes, deliverables, pedagogy, standards alignment
- `sessions.md` -- the Facilitator Training session content: overview, structure & tools, the modeled Walk the Walk session, wrap-up

#### A Playful Pedagogy

- **Play** - Discover *Threadbare* and analyze how stories unfold.
- **Create** - Build StoryQuests with characters, dialogue, and mini-games.
- **Share** - Contribute to the open-source *Threadbare* repository.
- **Reflect** - Learn from peer/mentor feedback and iteration.

#### Why *Threadbare*?

- A free, open-source, narrative-driven adventure puzzle game and learning experience, built with Godot and hosted on GitHub.
- Learners can remix code, write dialogue, create art, and collaborate with real developers to contribute culturally relevant and curriculum-aligned StoryQuests.
- Players step into the role of the StoryWeaver, restoring an unraveling world by recovering stories, traditions, and cultures.

#### Open Source

- It's a development model in which the software's source code is made publicly available.
- All *Threadbare* code and assets are openly licensed.
- When learners contribute to *Threadbare*, their work lives on!
- Even after the program ends, they can continue working on their StoryQuest, propose a new one, or even contribute to other parts of the *Threadbare* game.

### Part One (continued) - Structure & Tools

Section title slide: "Structure & Tools - Core: Threadbare"

#### StoryQuests

Even though *Threadbare* is a game with it's own Lore, Core: Threadbare focuses on StoryQuests:

- Each StoryQuest includes unique characters, settings, narrative, and objectives.
- Themes may be learner-chosen or curriculum-aligned.
- Learners begin with a template and customize it.
- StoryQuests can have 1-3 mini-games.

Learners submit upon completion of each Milestone and should follow the:

- Submission Criteria
- Technical Contribution Requirements
- Licensing Guidelines

Endless Maintainers approve/deny submissions.

#### Tools

- **GitHub** is a Cloud Hosting Service, or workspace, that includes tasks (issues) and tutorials for learners, a space to collaborate and share work, and the home of *Threadbare*, where the StoryQuest will be sent.
- **Git** is a Version Control System designed to handle both small and very large projects quickly and efficiently.
- **Godot engine** is a free, all-in-one, cross-platform game engine that makes it easy for students to create 2D and 3D games.

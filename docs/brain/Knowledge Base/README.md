# Studios Knowledge Base

A high-level knowledge base for Endless Access / Endless Studios, distilled from the LX Team project docs. Built to support three kinds of decisions: how programs are shaped, how onboarding should look, and what the community needs.

Last compiled: August 4, 2026. `Programs/` added August 5, 2026.

## How to use this folder

| File / folder | What it answers |
|---|---|
| `01-company-and-platform-overview.md` | Who we are, how the platform is structured, FY27 goals, safety and compliance ground rules |
| `02-programs-and-offerings.md` | What we run today, delivery models, credentials, and the partner landscape |
| `03-program-design-lessons.md` | Evidence-backed lessons on what works and what breaks in program design |
| `04-onboarding-insights.md` | The onboarding funnel, its known failure points, and design guidance |
| `05-community-needs.md` | Community philosophy, personas, Discord strategy, and the platform's community gaps |
| `Programs/` | The actual curriculum and session content for each program offering -- see `Programs/README.md` |

Each of the five numbered files ends with a "Decision levers" section -- the open choices the evidence points at, without prescribing an answer. `Programs/` is organized differently: it's the raw teaching material rather than a synthesis, so there are no decision levers there, just curriculum and sessions.

## Programs

`Programs/` holds one subfolder per program offering -- Core: Threadbare, Explore: Threadbare, Explore: Godot, and the Educator Training Program -- each with a `curriculum.md` (program shape, learning principles, outcomes, session or workshop map) and a `sessions.md` (the full session-by-session or workshop-by-workshop content, verbatim, ready to run). Core: Threadbare also has a `learner-playbook.md` for self-directed learner use. See `Programs/README.md` for the full index, one-paragraph summaries of each program, and a note on offerings that exist but don't have source material here yet (Explore: Git, On-Ramps, Core: Godot, More: Threadbare, Explore: fAIrytales).

## Source documents

All content in the five numbered files is drawn from these LX Team project docs (dates are as-captured):

- Product Info Dump (platform product context, April 2026)
- updates_may2026.md (developments since April 17, 2026)
- partner-program-feedback.md (partner and program feedback log, last updated May 7, 2026)
- explore-godot/ folder: Cohort Wrap-up, Retrospective, Session Debriefs, Platform Feedback -- Community Building (May 27, 2026), Platform Audit -- Requirements to Roadmap (A2 Studios, Nov 2025)
- Endless Access Service Blueprint -- Gap Registry (May 2026)
- endless_access_links.md (link inventory to primary Google Docs)

`Programs/` content is drawn from a separate extraction: the Google Slides decks for each program's sessions, plus the Facilitator Playbook and Learner Playbook Google Docs, extracted 4 August 2026. Each program's `curriculum.md` documents its own extraction and fidelity notes -- where the source decks were sparse or a speaker note didn't come through, that gap is flagged inline rather than filled in.

## Conventions

- *Threadbare* is italicized when referring to the game; program names (Core: Threadbare, Explore: Threadbare) are not.
- Game making is not hyphenated unless used as an adjective (a game-making program).
- Dashes are used instead of em dashes throughout.

# Programs & Offerings

## Program portfolio

Two primary program tiers, plus emerging additions:

### Core: Threadbare (flagship)
A structured, cohort-based game-making experience. Central milestone: creating and submitting a StoryQuest -- a Godot mini game for the live *Threadbare* repo, submitted via GitHub PR. Tied to the **Community Game Making** microcredential (7 criteria). Run at scale with UTP (GameLab cohorts, ~234 learners in GameLab 4.0; ~575 contributed in 2025) and at partner sites.

### Explore Series (shorter, modular)
- **Explore: Threadbare** -- 13 workshops (a 5-session variant exists for older learners). The only NDPA-compatible program in the MVP, so the default for US school partnerships.
- **Explore: Godot** -- 10 sessions. First Endless-led online cohort ran May 12 - June 11, 2026 (Tue/Thu, 90 min, free; 68 enrolled / 30 participated).
- **Explore: Git** -- version control fundamentals.
- Tied to the **Intro to Game Making** microcredential (3 criteria).

### On-Ramps and variants
Shorter modules used in partner configurations: Godot On-Ramp, Game Design On-Ramp, Git On-Ramp (e.g. Glasswing Module 1). Also in the field: Core: Godot (Jordan train-the-trainer program), More: Threadbare (follow-on), and workshop-only formats (KidzByte).

### Explore: fAIrytales (new, in development)
An Explore-tier program teaching learners to build AI-assisted mini games within the *Threadbare* world. Phase 1 (Setup) walkthrough complete with 14 documented sticking points; Phase 2 (Design) next. Strategy framing: lead with affirmative workforce opportunity before principles or constraints; UNESCO competency levels (Understand, Apply, Create) mapped per section.

## Delivery models in the field

| Model | Examples | Notes |
|---|---|---|
| Endless-led online cohort | Explore: Godot cohort 1 | Full control, high quality, staff-intensive |
| Partner-led, Endless-trained | Urban Arts, BGC, Glasswing | Live facilitator training required; quality varies with facilitator |
| Train-the-trainer | Jordan/Dimensions (1,375 learners, ~50 schools) | Scales furthest; translation and delivery fidelity are the risks |
| Self-delivery | KidzByte (India) | Speaker notes in decks confirmed sufficient as trainer guides |
| Instructor simulation | UTP (40-50 instructors take the course as learners, May-June 2026) | Pedagogical feedback before March 2027 launch |

## Enrollment model

Four layers: Program Template → Program Instance → Cohort → Enrollment Record. MVP uses URL-embedded access codes; target state is clean cohort invite tokens. Learner-facing language: avoid "cohort" -- prefer "live session" or "your group."

- **Active delivery**: Urban Arts (NYC), Black Girls Code, Glasswing (El Salvador, ~500+ students), UTP (Peru), Jordan/Dimensions, VRmont Cup/SeedVT, SMASH, KidzByte/JetSynthesis (India), Wichita Public Schools (rolling out across 9 high schools)

## Proof points worth leading with

- Jordan pre/post survey: Godot literacy +108%, GitHub/GitLab +71%, block coding +44%
- BGC: career interest in the games industry +15%
- Wichita: Marzano study showing 50% fewer behavior incidents and 11 more days of attendance from a gaming concepts class
- Urban Arts: the student with poor attendance who never missed game class -- and whose overall attendance improved when game work was made conditional on it
- Backstitch shareable playable links: peers playing each other's games live is the strongest "wow" moment we have
- Mentors and certificates are the two highest-rated motivators across programs (92.9% and 91.8% at UTP)

## Decision levers

- Portfolio balance: partners keep asking for configurable bundles (workshops + Explore: Godot for a microcredential; sequencing across segments). Clear rules for which combinations earn credentials would remove repeated one-off decisions (SMASH, Wichita, Glasswing all hit this).
- The "no experience required" promise doesn't match the current Explore: Godot reality -- it fits advanced beginners better than absolute beginners. Either build a true beginner track or qualify the framing.
- The microcredential + micro-internship pipeline is underleveraged as both a marketing asset and a program design anchor.
- Device reality at partners (Chromebooks at Girls Make Games, 4 computers for 37 students at KidzByte, locked-down Windows machines) should shape program requirements before content design.

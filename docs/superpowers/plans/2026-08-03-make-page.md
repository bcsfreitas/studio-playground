# Make Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `/make`, the maker-tools hub — web tools, Threadbare Tailor sub-apps, and external tool links, each launching in a new tab. No gating, no embedded iframe.

**Architecture:** A mock-data composable (`useMakeMockData.ts`) feeds a reusable `ToolCard.vue` component, rendered twice (web tools grid, Tailor grid) inside a new `make/index.vue` page that otherwise matches the shell/chrome of `app/pages/learn/index.vue`. A fourth section (external tools) renders plain link rows inline, no new component.

**Tech Stack:** Vue 3 `<script setup>`, Nuxt UI v4 (`UCard`, `UBadge`, `UButton`, `USeparator`), Tailwind CSS v4, `@nuxt/icon` (`lucide` collection). No test framework in this repo — verification is manual via `npm run dev`.

## Global Constraints

- Use Nuxt UI components, not hand-rolled HTML, per `CLAUDE.md`'s "Building UI" section — use `USeparator` for section dividers, never a `border-t`/`border-b` div.
- No i18n for this page — `learn/index.vue` (the closest sibling page, a catalog/listing page) uses plain hardcoded English strings, not `useI18n()`'s `t()`; Make follows that same convention, not the heavier i18n pattern used by the program cover page.
- No test suite exists — verify by running the dev server and viewing `/make` in the browser.
- No account gating, no embedded iframe tool frame, no Endstar launcher modal — every tool card/row is a plain link that opens `tool.url` in a new tab; a tool with no `url` yet renders a disabled button.

import type { ToolCardData } from '~/composables/useMakeMockData'

defineProps<{
  tool: ToolCardData
}>()
</script>

<template>
  <UCard :ui="{ root: 'h-full flex flex-col', header: 'p-0 relative', body: 'flex flex-col gap-2 flex-1', footer: 'pt-0' }">
    <template #header>
      <img v-if="tool.image" :src="tool.image" :alt="tool.name" class="h-28 w-full object-cover">
      <div v-else class="h-28 w-full flex items-center justify-center" :style="{ background: tool.logoBg }">
        <img :src="tool.logo" :alt="tool.name" class="h-10 w-auto">
      </div>
      <UBadge
        :label="tool.badge"
        :color="tool.badge === 'Live' ? 'success' : 'warning'"
        variant="solid"
        size="sm"
        class="absolute top-3 right-3"
      />
    </template>

    <div class="text-xs font-semibold text-dimmed uppercase tracking-wide">{{ tool.tag }}</div>
    <div class="font-heading font-bold text-highlighted">{{ tool.name }}</div>
    <p class="text-sm text-muted flex-1">{{ tool.blurb }}</p>

    <template #footer>
      <UButton
        block
        variant="soft"
        color="neutral"
        :icon="tool.isDownload ? 'lucide:download' : 'lucide:maximize'"
        :disabled="!tool.url"
        :to="tool.url"
        target="_blank"
      >
        {{ tool.isDownload ? 'Download' : 'Launch tool' }}
      </UButton>
    </template>
  </UCard>
</template>
